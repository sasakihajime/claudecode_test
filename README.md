# Todo App

シンプルで使いやすいTodoアプリケーションです。

## 機能

- ✅ タスクの追加
- ✅ タスクの完了マーク
- ✅ タスクの削除
- ✅ フィルター機能（すべて/未完了/完了済み）
- ✅ localStorageによるデータ永続化
- ✅ レスポンシブデザイン
- ✅ アニメーション効果

## 使い方

1. ブラウザで `index.html` を開きます
2. 入力欄に新しいタスクを入力し、「追加」ボタンをクリック（またはEnterキー）
3. チェックボックスをクリックしてタスクを完了/未完了にする
4. 「削除」ボタンでタスクを削除
5. フィルターボタンでタスクの表示を切り替え
6. 「完了済みを削除」ボタンで完了したタスクを一括削除

## ファイル構成

- `index.html` - HTMLファイル
- `style.css` - スタイルシート
- `app.js` - JavaScript（アプリケーションロジック）

## 技術スタック

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- localStorage API

## ブラウザサポート

モダンブラウザ（Chrome、Firefox、Safari、Edge）で動作します。
